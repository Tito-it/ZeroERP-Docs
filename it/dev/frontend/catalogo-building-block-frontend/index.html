Catalogo Building Block — Frontend¶

Inventario dei componenti riutilizzabili nel frontend Vue. Prima di implementare logica nuova, verificare se esiste già un building block adatto.

Documento vivo — aggiornare ogni volta che si aggiunge un building block.

useNotify useNotify.js Toast notifiche (success, warn, error, systemError)

useLoading useLoading.js Stato caricamento con distinzione first load (skeleton) vs successivi (progressbar)

useLookup useLookup.js Cache dati lookup generico (caricamento immediato o lazy)
useServerAutocomplete useServerAutocomplete.js Autocomplete server-side con debounce
useCodiceField useCodiceField.js Carica config sequenza codice (auto vs manuale, prefisso, separatore)
useReadonlyMode useReadonlyMode.js Modalità sola lettura basata su permessi utente (provider/consumer)

Classi pulsanti (main.css)¶

Classe Descrizione Uso
app-action-btn Pulsante azione form — icona verde (primary), no sfondo, grigio se disabilitato "Aggiungi", pulsanti azione generici nei form
app-manage-btn Pulsante gestione riga — icona blu (info), hover su sfondo blue-50 Pulsanti "Gestisci" nelle colonne azione DataTable (UoM, BoM, Note)
app-edit-btn Pulsante modifica riga — icona matita verde (primary), hover su sfondo primary-50 Matita nelle DataTable e card liste

app-reload-btn Pulsante ricarica lista — icona verde coerente Refresh nelle toolbar lista

Pattern standard per pulsanti riga:

<!-- Gestione (apre sub-drawer) -->
<Button icon="pi pi-box" text rounded size="small" class="app-manage-btn" @click="onManage(data)" />
<!-- Modifica -->
<Button icon="pi pi-pencil" text rounded size="small" class="app-edit-btn" @click="onEdit(data)" />
<!-- Elimina -->
<Button icon="pi pi-trash" text rounded size="small" class="app-delete-btn" @click="onDelete(data)" />

Lookup e Select¶

Componente File Descrizione
LookupSelect LookupSelect.vue Select generico per tabelle lookup whitelisted (id, codice, descrizione). Prop rel mappa alla whitelist in dbops_repository.py (~45 tabelle). Sostituisce il pattern useLookup(() => lookupCodici(...)) + <Select>. Props: rel (obbligatorio), placeholder, label-field (default descrizione), value-field (default id), show-clear, filter (default true), disabled. Emette @change.
ArticoloLookup ArticoloLookup.vue Autocomplete articolo server-side cross-dominio. Props: voce-utility, solo-componenti, solo-attivi, placeholder, disabled. Emette @select. Usa optionLabel PrimeVue 4, minLength: 3. Usato da: righe listino, distinta base, test resolver.
BillingAccountLookup BillingAccountLookup.vue Autocomplete BA server-side cross-dominio con ricerca ricca (codice, ragione sociale, id fiscale, PDP). Dropdown a 3 righe via classe app-lookup-option. Props: utilityId, soloValidi (default true), validAt, placeholder, disabled. Emette @select, @clear. Footer "affina la ricerca" quando total > limit. minLength: 2. Scope emittente automatico lato backend. Usato da: righe listino associazioni; esteso a preventivi/ordini/fatture/pratiche.
